1. Payoff table

Rules: each payoff is a finite number (negatives and decimals allowed). Each probability is a number from 0 to 1, and the probabilities must add up to 1. At least one alternative and one state are required.

2. Summary

EMV = sum of payoff × probability. Regret = best payoff in a state among all alternatives − this alternative's payoff; Max regret is its largest regret. Results show two decimals; calculations keep full precision. Values within 10⁻⁹ are treated as tied.

Regret table

3. Criterion decisions

Each criterion compares the complete original set, so different criteria can recommend different alternatives.

4. Staged filtering

Stages apply in order and only look at the previous survivors. Eliminated alternatives never come back, statistics come from the full table, and ties at the cutoff all survive.

5. Flow diagram

Solid arrows connect survivors. Dashed branches show the alternatives eliminated at each stage.
